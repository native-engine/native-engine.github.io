## UTILITIES • УТИЛИТЫ

Game archives packager: A BASH script that compiles Lua scripts into LuaC and packs game archives using a custom-built utility called AssetCompressor; eventually, these functions will be integrated into the game editor.

Упаковщик игровых архивов: BASH-скрипт, компилирующий Lua-скрипты в LuaC и упаковывающий игровые архивы самописной утилитой AssetCompressor, со временем эти функции войдут в состав игрового редактора.
